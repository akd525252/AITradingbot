# Gain EX — Strict Agent Operation Rules

The following custom operational rules must be strictly adhered to by the Antigravity agent at all times during workspace operations:

1. **Unrequested File Modification Block:**
   * Never modify or touch any file that has not been explicitly requested or targeted by the user.

2. **Logical Preservation Directive:**
   * Never change, refactor, or adjust any business, calculation, pricing, simulation, database, or routing logic unless it is explicitly requested.

3. **Written Confirmation Mandate:**
   * Even if a logical change or file update seems required to fulfill a request, you must first ask the user in writing and present the proposed modifications.
   * Only proceed with execution once the user has explicitly approved the changes in writing.

4. **Browser Agent Usage Block:**
   * Never launch a browser agent to verify a completed task.
   * When a task is finished, summarize what was done directly in the chat and provide clear step-by-step instructions for how the USER can manually verify the changes in their own browser.
